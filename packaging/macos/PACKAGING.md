# CLinter macOS ARM64 packaging

From the repository root:

```sh
bash packaging/macos/build_dmg.sh
```

Output: `builds/packages/CLinter-1.0.0-macos-arm64.dmg` and `.sha256`.

The script deliberately fails when required release inputs are missing. For an incomplete packaging smoke test only:

```sh
bash packaging/macos/build_dmg.sh --allow-missing
```

Provide custom paths to source files as environment variables if filenames differ:
`CLINTER_DUCK720`, `CLINTER_DUCKD1`, `CLINTER_DUCKTEXT`, `CLINTER_REGTEST`, `CLINTER_MANUAL_EN`, `CLINTER_NEBULA`.

For example:

```sh
CLINTER_MANUAL_EN="$HOME/Documents/CLinter_BASIC_Manual_EN.pdf" \
bash packaging/macos/build_dmg.sh
```

For release, test on a clean Mac and sign/notarize the application and disk image before publication. This script does not perform signing/notarization.

The icon is generated by `iconutil` from `CLinter.iconset` and stored as `Contents/Resources/CLinter.icns`. Examples and the English manual remain outside the `.app`.
